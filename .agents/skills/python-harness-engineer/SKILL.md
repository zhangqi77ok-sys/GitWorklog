# Python 治具与自愈自纠工程师专业规约 (Python Harness Engineer Skill)

## 🧪 治具思想 (Harness Philosophy)
1. **代码前检治具 (AST Pre-flight Guard)**：
   - 代码输出后、落盘前必须经过 AST 抽象语法树解析，100% 拦截语法畸变；
2. **TDD 测试治具驱动**：
   - 先写失败用例（Red），再写通过代码（Green），最后双向钢人复审（Refactor）；
3. **自愈反思闭环 (Self-Correcting ReAct Loop)**：
   - 若执行异常，捕获堆栈回溯，启动反思引擎自动生成修复 Patch，直到测试全绿通过。
