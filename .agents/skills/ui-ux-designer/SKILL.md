# UI/UX 体验设计专业规约 (UI/UX Designer Skill)

## 🎨 视觉系统核心准则 (Design System)
1. **低疲劳色盘**：
   - App Base: `#FAF8F5` (柔和暖米白纸质基底，消除冷白刺眼强反光)；
   - Surface: `#F4EFEA` (工具栏与侧面板自然分层)；
   - Primary Accent: `#D96B27` (低饱和陶土暖橙，用于聚焦、强调与主动作)；
   - Terminal/Code: `#1E1C1A` (暖炭黑底色搭配 `#A3E635` 柔和荧光绿)；
2. **极简克制原则**：
   - 彻底禁用：大号笨重圆角按钮、拟物阴影、无意义的装饰性卡片网格；
   - 控件尺寸偏小克制（标准高度 24-28px），保持极高有效代码阅读面积；
3. **人体工程学布局 (Ergonomics)**：
   - 16:9 原生三栏布局：[42px 活动栏] | [240px 会话与文件树] | [弹性 45% 对话推理流] | [弹性 55% 代码预览与底部抽屉终端]；
   - 代码区上方严格保持纯净文件标签页，杜绝混杂系统功能标签。
