# RunCabinet · Vite Coding Studio

Windows 原生桌面端智能编程与多智能体协同开发工作台（集成 cockpit-tools 模型网关架构）。
- **cockpit-tools 模型网关**：多厂商（Antigravity、Gemini、Trae、Qoder、Kiro 等）、多账号热切换、配额与重置时间监控；
- **免登录纯本地**：开箱即用，直达工作台；
- **暖色调高颜值桌面**：RunCabinet 陶土暖橙与砂岩微光材质；
- **积木式解耦架构**：通过 EventBus 与轻量路由通信；
- **核心功能**：会话标签颜色/删除/分享、Obsidian 代码知识图谱、分层记忆、多 Agent 流水线、Cockpit 调试沙箱与 Token 实时计量。
