## 📁 二、多项目树状多会话管理系统 (Project-Tree Session Management)

> 💡 **核心产品逻辑架构**：
> ```text
> 📁 项目 A (D:\weihu\agent-learning) [当前激活] [➕新建会话]
>   ├─ 📌 会话 1: 网关二阶级联与调度架构设计 [#架构重构]
>   ├─ 💬 会话 2: 修复 WebView2Loader 缺失 [#Bug修复]
>   └─ 💬 会话 3: 项目初始化与探索 (默认)
> 📁 项目 B (D:\weihu\sub2api) [展开/折叠] [➕新建会话]
>   ├─ 💬 会话 1: 调研 Ingress 认证流与协议转译
>   └─ 💬 会话 2: 账号池熔断机制分析
> ➕ 打开新项目 (Open Project Folder)
> ```

### 2.1 业务交互闭环说明
1. **多项目并行共存**：
   * 左侧列表同时展示开发者打开的多个本地项目；
   * 每个项目可独立展开或折叠；
   * 点击某个项目下的会话时，**系统自动将当前工作区与右侧编辑器、终端 CWD 切换至该项目**，实现会话与工程完全对齐。
2. **首次添加项目自动建首会话**：
   * 点击 `[➕ 打开本地项目]` 选择本地文件夹后，系统若检测到该项目尚无会话，**自动创建【会话 1: 项目初始化与探索 (默认)】** 并立即展开；
3. **项目级别的独立操作**：
   * 悬浮项目行：显示 `[➕ 为该项目新建会话]` 与 `[⋮ 项目菜单]`（关闭项目、在资源管理器中打开、移除）；
4. **会话级别的增强功能**：
   * **全局/项目搜索 (`Ctrl+K`)**：快速匹配所有或当前项目下的会话标题与内容；
   * **打标签 (`Tags`)**：为会话添加彩色标签（如 `#架构重构`、`#Bug修复`、`#单测`），支持顶部点击标签一键过滤；
   * **置顶 (`Pin to Top`)**：置顶的会话固定在该项目会话列表的最上方，带专属橙色图钉；
   * **行内重命名**：双击会话标题直接行内修改名称。
