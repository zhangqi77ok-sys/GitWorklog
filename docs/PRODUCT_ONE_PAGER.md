# Tcode 产品一页纸 (Product One-Pager)

> **产品定位**：企业级安全、可审阅、可验证且完全可回滚的 Agentic AI 智能编码工作台 (Agent Coding IDE)。

---

## 🎯 一、核心定位与第一目标用户

### 1. 第一目标用户 (Target User)
**需要对 AI 生成的代码变更进行严格审阅、测试验证与无损回滚的专业研发工程师与企业架构师。**

### 2. 非目标用户 (Non-Goals)
- 仅需要简单代码补全/单行问答的初学者（推荐使用 GitHub Copilot / Cursor 基础 Tab 模式）；
- 追求全自动黑盒执行且不关心单测质量的用户。

---

## 💡 二、解决的核心痛点 (Problems Solved)

1. **AI 修改不可控与代码污染**：传统 AI 编程工具直接全量覆盖文件，破坏未保存代码；Tcode 提供**精细化 Hunk 级审查**与**写盘前 Git 影子快照 (Shadow Checkpoint)**，支持一键无损撤回。
2. **测试结果与命令执行脱节**：命令输出存在 `FFFF` 失败但误判为完成；Tcode 深度绑定测试输出，**单测未全量通过前绝对禁止标记为完成**。
3. **模型上下文黑盒与凭据泄露**：Token 水位计算混乱且源码硬编码 API Key；Tcode 提供**统一全局上下文遥测与非破坏性智能压缩**，源码与日志 100% 物理脱敏隔离。

## 🔒 四、核心差异化能力 (Core Differentiators)

- **物理级 Air-Gapped 离线断网守卫**：在宿主网关层硬阻断一切公网出站请求；
- **真实 Git 影子快照回滚**：每次 Agent 动作前自动打下微版本，点击“↩ 回到这里”即刻在磁盘物理回滚代码与对话；
- **结构化测试资源管理器 (Test Explorer)**：失败用例直接提取源码位置 (`test.py:42`)，一键跳转与靶向修复。

## 📦 五、架构与发布交付规范

- **产品正式品牌**：`Tcode`（内核代号 `Tcode`，Agent 统一为 `Tcode Agent`）；

- **未来演进路线**：`Tauri v2 + Rust Core 原生轻量化`；
