# Tcode 全局异常与安全阻断状态清单 (Exception & Safety Spec)

作为企业级安全 AI 编程工具，Tcode 对任何异常均定义了明确的原因、影响范围、阻断机制与可恢复动作。

---

| 异常代码 | 触发场景 | 影响范围 | 阻断机制 | 用户的下一步恢复操作 |
|---|---|---|---|---|
| **ERR_AIR_GAPPED_BLOCKED** | 开启离线隔离模式时 Agent 尝试调用外部网络命令（如 `curl`, `git push`） | 仅阻断当前出站指令 | 宿主网关抛出安全拦截，不予执行 | 1. 确认是否使用本地镜像/本地模型；<br>2. 若确需联网，请在设置中临时关闭 Air-Gapped 模式。 |
| **ERR_TEST_SUITE_FAILED** | Agent 修改代码后执行单元测试存在 `FAILURES` 或 `ExitCode != 0` | 阻断验收完成标记 | 禁止向用户汇报“任务已完成”，强制进入自愈循环 | 1. 允许 Agent 自动根据单测 Trace 进行自愈；<br>2. 或点击「↩ 回到这里」一键回滚。 |
| **ERR_TOOL_EXEC_TIMEOUT** | 本地终端命令执行超过 30 秒（如陷入死循环或等待交互输入） | 终止该进程 | 宿主自动发送 SIGKILL 并回收管道资源 | 1. 检查测试或构建脚本是否包含阻塞式等待；<br>2. 调整指令参数为非交互模式 (如 `-y` 或 `--non-interactive`)。 |
| **ERR_CONTEXT_OVERFLOW** | 连续多轮复杂对话总 Token 数接近模型物理上限 (>=95%) | 上游模型无法接受长文本 | 触发 `force_compress` 智能无损压缩 | 1. 系统自动剥离历史推演中间态；<br>2. 如需全新起点，点击「新建自由会话」开始隔离上下文。 |
| **ERR_FILE_WRITE_COLLISION** | 目标代码文件在写盘时检测到外部未保存冲突 | 暂停写盘 | 触发 Diff 冲突警告弹窗 | 1. 点击查看 Diff 确认差异；<br>2. 选择“覆盖写盘”或“回滚本次修改”。 |
