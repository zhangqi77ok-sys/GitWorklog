## 一、产品定位与核心理念

### 1.1 项目级三位一体研发铁律 (Project-Level Iron Rules)
1. **双向强同步原则**：凡有需求、原型或功能的变更，必须无条件同时同步更新 `docs/` 下的 PRD 文档与 `prototype/` 下的交互原型；
2. **零越界开发禁令**：没有进行充分需求澄清和完整原型设计确认，绝对不准提前进入项目开发；
3. **功能原型必须具备真实交互**：凡涉及到功能的原型，必须具备完整可交互的页面与状态流转，杜绝不可操作的静态空壳。


当前 AI 编程行业陷入两极分化：
- 一端是商业闭源软件（如 Cursor），强制将代码上传云端索引，收取高昂订阅费且无法连接企业自建大模型；
- 另一端是开源方案，要么直接 Fork 臃肿的 VS Code（如 Void、PearAI，安装包 350MB+，启动吃力），要么是纯黑框 CLI 终端（如 Aider，缺乏直观的可视化协同），要么是纯对话框套壳（如 Cherry Studio，无法落地编辑真实工程）。

**CodeMind-Hub 的破局之道**：
采用 **Tauri v2 + Rust 微内核 + React 19 原子积木**，打造包体积 `< 50MB`、内存占用 `< 150MB`、冷启动 `< 1s` 的原生桌面 IDE。在底层融合 Aider 的精炼哲学与大模型 Transformer 运行机制，建立全链路 **80%~95% 极致省 Token 引擎**，并通过 **Git 影子快照与双轨权限** 赋予开发者最高掌控感。

## 三、四大核心系统底座 (Four Foundational Pillars)

```
                              ┌─────────────────────────────────────────────────────────┐
                              │            CodeMind-Hub 四大核心系统底座                 │
                              └────────────────────────────┬────────────────────────────┘
                                                           │
        ┌──────────────────────────┬───────────────────────┴──────────────────┬──────────────────────────┐
        ▼                          ▼                                          ▼                          ▼
【1. 总线-子线底座】        【2. 积木解耦底座】                       【3. 极致省Token底座】      【4. 安全系统底座】
- 单例调度总线 GatewayBus   - 表现积木 (标题/树/聊天/终端)             - 确定性KV Cache前缀对齐   - Git 影子快照秒级回退
- 插拔子线 (Claude/Ollama)  - 核心积木 (AST/Diff/Memory)              - AST 骨架剪枝 (省96%)     - 权限双轨制 (人审 vs 自决)
- 零耦合、热插拔与秒级熔断  - 独立成块，无循环依赖，高内聚可单测       - 原子级精准 Diff Patch    - AST 语法落盘前置防御
```

### 3.1 总线与子线架构底座 (Bus & Subline Substrate)
- **中央调度总线 (`GatewayBus`)**：作为唯一的单例中枢，只负责状态流转、上下文路由与事件分发，不夹带任何具体厂商特化代码；
- **标准化子线插槽 (`IProviderSubline`)**：Claude、OpenCode、Codex、阿里百炼、本地 Ollama 及 MCP 工具均以标准独立子线挂载，支持秒级热切与故障平滑降级。

### 3.2 搭积木解耦底座 (Decoupled Building-Blocks Substrate)
- 拒绝过度封装的复杂继承，坚持模块原子化：
  - **表现积木**：Titlebar、ActivityBar、LeftPanel、ChatColumn、EditorWorkspace；
  - **核心积木**：AST 语法分析器、Unified Diff 补丁器、Memory 记忆网格、Test 治具运行器；
  - 每个积木块均拥有独立的接口契约，可独立替换、独立单测、独立组装。

### 3.3 极致省 Token 认知底座 (LLM-Native Extreme Token Efficiency Substrate)
站在 AI 模型底层原理（Transformer 注意力机制、KV Cache 前缀复用与自回归输出代价）的最高维度，全流程压缩 Token 开销：
1. **确定性静态前缀流水线 (KV Cache 95% 命中率)**：系统规则与工具定义严格冻结在 Token 序列头部，动态上下文严格置于尾部，确保 **KV Cache 命中率稳定在 90%~95% 以上**，享受 90% 降价与 10x 提速；
2. **AST 骨架代码剪枝 (AST Skeleton Pruning)**：跨文件关联时自动剔除函数具体实现（`{ ... }` / `pass`），仅保留接口签名、类型定义与 Docstring，**从 2,500 Token 瞬间压缩至 80 Token（缩减 96%）**；
3. **按需原子 Patch 替代全量重写**：修改 1000 行文件中的 3 行时，强制输出原子 Search/Replace 块，**输出消耗由 1,200 Token 降至 25 Token**；
4. **智能终端与编译器噪声抑制**：Rust 微内核在进程管道层剥离进度条转轮与冗余告警，仅向 LLM 喂入关键 Error 行（减少 90% 终端输出 Token）；
5. **分级滑动记忆网格 (L0/L1/L2)**：L0 恒定核心规则 + L1 自动浓缩决策事实 + L2 滚动明细，杜绝长会话 Token 爆炸与失忆。

### 3.4 安全系统底座 (Security & Reversible Substrate)
- **Git 影子快照与秒级回退**：写入操作前自动建立快照（`[CodeMind Checkpoint]`），界面提供常驻 **`↩️ 影子回退`** 按钮，一键秒级 `git reset --hard`；
- **双轨权限治理**：一键切换 `[ 🛡️ 逐次审核 ]` 与 `[ 🤖 智能决策 ]`；
- **AST 语法防腐门禁**：落盘前在内存中校验语法，严防半截残缺代码；
- **无窗口静默进程隔离**：Tauri Rust 原生通道调用，消除 Windows 弹窗黑框干扰。

### 4.2 一级三态定义与固定标记
1. **🌐 全局自由会话大类**：不选项目、不选文件，打开即聊；常驻展示 `[ 🌐 全局自由会话 ]`，随时可一键 `[ ➕ 关联到工程 ]` 升级；
2. **📁 工程级会话大类**：先选项目，在项目下统领全盘；常驻展示 `[ 📁 工程: agent-learning (🌿 main) ]`，统筹多文件跨模块协同；
3. **📄 文件专精会话大类**：先选具体文件，针对单个文件开聊；常驻展示 `[ 📄 文件: src/bus/GatewayBus.ts ]`，点击瞬时在编辑器高亮联动，**立省 80% Token**！


### 4.4 底栏模式与模型动态调度交互规范 (Mode & Model Selector System)
1. **Plan / Act 聚合下拉弹窗按钮 (Unified Mode Selector)**：
   - 将原先并排平铺的 Plan 和 Act 按钮**高度融合为一个单体聚合按钮**，位于输入框底栏；
   - **默认状态为 `[ ⚡ Act 落地模式 ▾ ]`**，主色为低饱和陶土暖橙 (`#D96B27`)；
   - 点击弹出轻量选择浮层（Mode Dropdown Popover）：
     - `⚡ Act 落地模式 (Default)`：AI 执行修改代码、写入补丁并运行治具自纠错；
     - `📐 Plan 规划模式`：AI 仅深度分析工程 AST、拆解执行计划，严格不修改任何实际代码；
   - 切换后按钮文本即时更新，输入框提示词与上下文策略自动联动自适应。

2. **模型动态选择与秒级热切按钮 (Model Switcher Cockpit)**：
   - 输入框底栏常驻模型选择按钮，如 `[ 🧠 Claude 3.5 Sonnet ▾ ]`；
   - 点击弹出高保真多厂商模型矩阵选择窗，包含：
     - **Anthropic**: `Claude 3.7 Sonnet (Thinking)`, `Claude 3.5 Sonnet`
     - **DeepSeek**: `DeepSeek-R1 (Thinking)`, `DeepSeek-V3`
     - **OpenAI**: `GPT-4o`, `o3-mini`
     - **Local / Ollama**: `Qwen 2.5 Coder 32B (Local)`, `DeepSeek-Coder 7B`
   - **秒级热切联动**：用户点击任一模型，无需重启会话，GatewayBus 自动切换对应子线插槽，标题栏 Token 计费单价与上下文最大窗口尺寸（`contextMaxTokens`）即时无感联动更新！

### 4.3 界面导航与常驻两级面包屑
- **左侧面板三段式分流器**：`[ 🌐 全局 (3) ] | [ 📁 工程 (12) ] | [ 📄 文件 (5) ]`，按大类清爽过滤；
- **对话区顶部两级面包屑**：

### 4.5 右侧工作台区块与终端交互架构规范 (Workspace & Multi-Terminal Ergonomics)
1. **右侧工作台区块弹性开关 (默认关闭)**：
   - 右侧代码与产物工作台区块支持随时**折叠关闭与展开打开**；
   - **默认状态为：关闭 (Closed)**，界面呈对话流大视野沉浸模式；
   - 顶部工具栏常驻 `[ ◫ 打开工作台 / 代码与终端 ]` 胶囊开关，点击以平滑弹性动效展开右侧区块；
   - 对话流中产生代码 Diff 或文件改动时，支持自动/提示点击一键滑开。

2. **右侧区块 4:6 黄金纵向分割**：
   - 当右侧工作台展开时，垂直方向按照 **终端 (40%) : 代码与文件 (60%)** 严格排布；
   - 终端区支持单键收起与展开（收起时代码区撑满 100%）。

3. **多终端多标签并发调度 (Multi-Terminal Tabs)**：
   - 终端顶部配备标签栏：支持 `[ >_ 终端 1 (zsh) ]`、`[ >_ 终端 2 (pwsh) ]`、`[ >_ 编译任务 (npm dev) ]`；
   - **新建终端**：标签右侧常驻 `+` 按钮，一键瞬时创建独立终端进程；
   - **标签切换**：点击标签秒级切换对应终端会话与独立上下文输出；
   - **关闭终端**：标签自带 `x` 快捷关闭按钮；
   - **开关联动**：提供右侧折叠按钮，支持一键临时收起/展开终端。


### 4.6 工作台全功能模块交互规范 (All Core Workspace Modules)
为了杜绝“纯聊天框套壳”，CodeMind-Hub 必须具备完整的工业级桌面 IDE 全套核心模块体系：

1. **项目代码资源管理器 (File Explorer Panel)**：
   - 真实呈现当前工作区工程的文件树目录（支持文件夹递归折叠与展开）；
   - 支持主流代码与配置文件类型专属图标展示（`.ts`, `.tsx`, `.json`, `.css`, `.md` 等）；
   - 顶部提供快捷动作：`[ ➕ 新建文件 ]`、`[ 📁 新建文件夹 ]`、`[ 🔄 刷新树 ]`、`[ 展开/折叠全部 ]`；
   - 单击文件以斜体临时预览标签打开，双击固化为常驻标签。

2. **全局跨文件符号检索 (Global Search Panel)**：
   - 支持多维度搜索匹配：大小写敏感 (`Aa`)、全词匹配 (`|ab|`)、正则表达式 (`.*`)；
   - 跨文件分组展示匹配结果，显示文件名、匹配行号与高亮代码上下文；
   - 点击任一搜索结果条目，右侧代码区瞬时联动跳转至对应文件的指定行号并高光高亮。

3. **Git 影子快照与版本控制中心 (Git & Shadow Snapshots Panel)**：
   - **分支管理**：常驻显示当前 Git 分支，支持秒级切换分支；
   - **未暂存/已修改文件清单**：清晰列出 `M (Modified)`、`A (Added)`、`D (Deleted)` 变更；
   - **自动化影子检查点时间线 (Shadow Checkpoints Timeline)**：
     - 显式列出 AI 在每次写盘前自动创建的 `[CodeMind Checkpoint]` 快照；
     - 每个快照条目右侧配备 **`[ ↩️ 一键还原至此快照 ]`** 动作按钮，秒级回滚。

4. **模型网关驾驶舱与 MCP 工具生态 (Gateway & MCP Cockpit Panel)**：
   - **多厂商渠道健康看板**：实时检测并展示 Anthropic (Claude)、DeepSeek、OpenAI、本地私有 Ollama 的联通状态与毫秒级延迟；
   - **MCP 工具服务器管理 (Model Context Protocol)**：

## 十、真实 Coding 痛点洞察与八大杀手级进阶功能

1. **防偷懒占位符 (`// rest of code ...`)**：内存级前检拦截，强制采用精确 Unified 原子 Patch，绝不大面积重写覆盖；
2. **长会话 Token 爆炸与遗忘症**：分级上下文压缩总线 (L0核心/L1事实/L2滚动)，立减 70% Token 且不失忆；
3. **死循环调试旋涡**：错误特征指纹追踪，连续 3 次未解触发熔断，自动回退到健康快照并弹卡由人选择；
4. **改公共接口漏改调用方**：AST 符号反向引用雷达，修改 Export 符号时自动将所有下游引用者加入任务列表；
5. **终端 500 行日志塞爆上下文**：Rust 底层剥离进度条转轮，浓缩提炼关键 Error 行，节省 90% 终端输出 Token；
6. **任务自适应模型分流**：Plan 用思考模型（DeepSeek R1/Claude），Act 用极速代码模型（Qwen/Ollama），自带费用看板；
7. **涉密内网数据绝对安全**：一键断网切换至纯物理离线模式，微内核硬阻断外网，仅绑定本地 Ollama；
8. **高频指令重复输入**：积木式斜杠快捷指令库，输入 `/` 瞬间呼出 `/review`、`/test`、`/doc` 动作模板。
