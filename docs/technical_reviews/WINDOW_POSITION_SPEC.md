# Windows 窗口首次启动居中规范

## 目标
确保 Tcode 每次首次启动以及安装后首次启动时，窗口出现在当前显示器可用工作区的居中位置，而不是左上角或超出屏幕。

## 范围
- 生产宿主：`src-desktop/desktop_app.py` 的 PyWebView 窗口。
- 安装器：`setup_wizard.py` 只负责启动宿主，不负责决定宿主位置。
- 当前版本不实现跨启动的用户窗口位置恢复；后续可增加窗口几何持久化，但不能影响首次启动居中。

## 契约
`center_window(work_area, window_size) -> (x, y)`：
- `work_area` 为 `(left, top, right, bottom)`，代表扣除任务栏后的可用工作区。
- `window_size` 为 `(width, height)`。
- 返回位置使窗口在工作区内居中。
- 当窗口大于工作区时，位置仍不得超出工作区左上边界，返回值为工作区左上角或对应安全边界。
- 支持负坐标工作区，兼容副显示器位于主显示器左侧/上方。
- 不依赖 UI、PyWebView 或 Windows API，便于单元测试。

## 启动规则
1. 优先使用当前显示器工作区，而不是整块屏幕尺寸；
2. 首次启动和没有合法保存几何信息时使用居中位置；
3. 安装器启动 `Tcode.exe` 后由宿主统一执行同一居中逻辑；
4. 不用 `GetSystemMetrics(0/1)` 直接假定主屏，也不把异常位置默认为 `(0, 0)`。

## 验收标准
- 1920x1080 工作区、1440x900 窗口返回 `(240, 90)`；
- 工作区存在任务栏偏移时，位置根据工作区坐标计算；
- 副屏负坐标工作区返回负坐标且仍然居中；
- 窗口比工作区大时不产生正向越界；
- 未改变安装器启动参数，安装后启动与普通快捷方式启动使用同一宿主逻辑。
